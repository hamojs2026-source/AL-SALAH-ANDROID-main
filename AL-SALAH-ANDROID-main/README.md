# الصلاة — AL-SALAH by MAS

تطبيق أندرويد أصلي لمواقيت الصلاة والقبلة والأذكار، مبني باستخدام Kotlin وJetpack Compose.

## حالة التطوير

المشروع يبدأ بالمرحلة الأولى: تأسيس هيكل Android وواجهة عربية RTL وإعداد البناء التلقائي عبر GitHub Actions. الميزات الدينية والحسابات الفعلية ستُضاف وتُختبر على مراحل لاحقة.
